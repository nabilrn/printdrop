# PrintDrop

PrintDrop is a lightweight, local-first file receiver for print shops.

The product goal is simple: a print-shop operator launches one small Windows application, a customer scans a QR code from any modern phone, sends a file without logging into WhatsApp or another account, and the file arrives on the shop PC ready for the operator to handle.

The repository is being bootstrapped around a native C core, Windows 7-to-11 compatibility, a minimal HTML/CSS/JavaScript sender, and CI-gated changes.
